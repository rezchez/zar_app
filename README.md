# زر فولیو اندروید

اپلیکیشن بومی زر فولیو با Jetpack Compose، نسخهٔ `1.1.1`.

## قابلیت‌ها

- ورود با ایمیل یا شمارهٔ همراه و رمز عبور؛ ورود دومرحله‌ای با کد رمزساز یا OTP ایمیلی در صورت فعال بودن حساب.
- نگهداری رمز‌شدهٔ توکن PocketBase با Android Keystore و ارسال آن به وب‌اپ با Bearer Authorization.
- انتخاب و ذخیرهٔ مستقل نشانی اتصال محلی و سرور از صفحهٔ ورود؛ توکن هر اتصال بر اساس شناسهٔ جداگانه نگهداری می‌شود.
- تغییر حالت روز و شب با حفظ انتخاب کاربر.

فونت Iran Sans در فایل‌های پروژه موجود نبود؛ متن بدنه فعلاً از sans-serif خود اندروید استفاده می‌کند و تیترها با Doran نمایش داده می‌شوند.
- جست‌وجوی اتیکت‌های موجود با بارکد، نام، کد کالا، محل نگهداری یا توضیح.
- انتخاب اتیکت و گرفتن عکس با دوربین دستگاه؛ عکس JPEG به مسیر امن اتیکت آپلود و در سرور بهینه می‌شود.
- نمایش فهرست آخرین اتیکت‌ها و مبلغ قیمت با واحد صحیح ریال.

## تنظیم سرور

در صفحهٔ اتصال، نشانی **وب‌اپ Next.js زر فولیو** را وارد کنید؛ برای نمونه `https://zar.example.com`. نشانی مستقیم PocketBase قابل استفاده نیست، چون بررسی ورود و مجوزها در وب‌اپ انجام می‌شود. برای سرور عمومی HTTPS لازم است. HTTP فقط برای میزبان محلی یا شبکهٔ خصوصی پذیرفته می‌شود.

حساب کاربری باید مجوز `document.view` برای جست‌وجو و مجوز `document.edit` یا `document.manage` برای بارگذاری عکس داشته باشد. مجوزهای سمت سرور همچنان برای هر درخواست بررسی می‌شوند.

## قرارداد API

| کار | مسیر | درخواست |
|---|---|---|
| ورود | `POST /api/auth/login` | JSON شامل `email`، `password` و در مرحلهٔ دوم `mfaId`، `otpId`، `otpCode` یا `totpCode` با `authMethod` |
| جست‌وجو | `GET /api/etiquettes?search=...&status=available` | احراز هویت Bearer؛ پاسخ شامل `items` |
| عکس محصول | `POST /api/etiquettes/{id}/image` | `multipart/form-data` با فیلد `image` و JPEG |
| دریافت عکس | `GET /api/etiquettes/{id}/image` | احراز هویت Bearer؛ پاسخ تصویر و بدون ذخیره در cache مشترک |

برای ورود اندروید، درخواست ورود سربرگ `X-Zarfolio-Client: android` دارد؛ فقط این پاسخ موفق شامل توکن JSON است و `Cache-Control: no-store` دارد. ورود وب همچنان از کوکی HttpOnly استفاده می‌کند. پاسخ جست‌وجو و بارگذاری تصویر بر اساس مجوزهای حساب جاری محدود می‌شود.

## ساخت و بررسی

نیازمندی‌ها: JDK 17، Android SDK API 36 و Gradle Wrapper همراه پروژه.

```bash
./gradlew :app:testDebugUnitTest :app:assembleRelease
```

APK در `app/build/outputs/apk/release/app-release.apk` ساخته می‌شود. این خروجی محلی با کلید debug امضا می‌شود؛ انتشار فروشگاهی به کلید امضای خصوصی نیاز دارد.
